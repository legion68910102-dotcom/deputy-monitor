# Личные копии приложения: устройство A не меняет устройство B

Приложение «Цифровой профиль депутата» использует статический GitHub Pages. По ссылке каждый человек получает **одинаковые исходные общедоступные данные**, но все его изменения сохраняются **локально в том браузере**, где он их сделал. Никакой общий API для записи посетителями в проект не предусмотрен.

## Что может делать посетитель

- Открыть сайт на Android, iPhone или ПК.
- Добавлять свои публикации вручную или импортировать CSV; редактировать и локально скрывать публикации через раздел **«🔒 Личное пространство»**.
- Изменять биографические сведения и фотографии в своей копии, менять районы, скрывать/возвращать карточки из архива в поддерживаемых разделах. Эти действия используют \`localStorage\` и **не пишут** в GitHub.
- Скачать личную резервную копию в JSON и восстановить её в другом браузере. **Это единственный способ вручную перенести локальные изменения на другое устройство**; автоматической синхронизации личных правок нет.
- Очистить свои правки, не затрагивая других пользователей. Удаление базовой опубликованной записи через интерфейс означает **«скрыть только у меня»** — исходная запись не удаляется из публичной базы.

## Где лежат данные

- Общие: \`deputies.json\`, \`vk-posts.json\`, \`ai-analysis.json\` и другие опубликованные файлы из GitHub. Их обновляет владелец/разрешённые GitHub Actions, и эти обновления **отображаются у всех**.
- Личные: \`dm_posts\`, \`dm_deputy_bio\`, \`dm_deputy_photos\`, \`dm_districts\`, \`dm_extra_deputies\`, \`dm_district_edits_v113\`, \`dm_deputy_archive_v114\`, \`dm_official_profiles_v114\`, \`dm_undo_v115\`, \`dm_personal_post_changes_v1\`. Сохраняются в \`localStorage\` конкретного браузера.
- Временная копия публичного VK: \`sessionStorage.dm_vk_posts\`, не включается в личный резервный файл. Её можно повторно загрузить из общей базы.

**Область хранения:** один браузерный профиль и адрес сайта. Несколько людей в **одном браузерном профиле на одном устройстве** могут видеть общие локальные правки. Для строгой изоляции на общем ПК используйте отдельные профили браузера или отдельные устройства. Режим инкогнито может терять изменения при закрытии.

**Утрата данных:** очистка данных сайта, переустановка браузера, смена устройства и ограничения объёма хранилища могут удалить личные правки. Регулярно скачивайте JSON и храните его в безопасном месте. Резервный JSON не шифруется и может содержать персональные тексты и фотографии: не отправляйте его посторонним.

## Порядок проверки изоляции

1. Откройте сайт на телефоне A и ПК B. Выберите одну публикацию, запомните текст.
2. На телефоне A откройте «🔒 Личное пространство», найдите публикацию, измените её текст или скройте. Сайт перезагрузится.
3. На ПК B обновите страницу: изменения с телефона A **не появятся**.
4. На телефоне A нажмите «Сохранить мои данные». Это скачает JSON с локальными правками.
5. На другом устройстве можно специально импортировать этот JSON, если хотите вручную перенести именно эти личные правки.

## Защита оригинала и права

- **Открыть публичную ссылку не означает получить права на репозиторий.** У посетителя нет кнопок записи в \`main\` или удаления опубликованных файлов.
- Последняя резервная ветка \`backup/v129-2026-11-23-tested-vk-collector\` имеет активные GitHub Rulesets: запрет удаления, обновления, force push.
- Главная ветка \`main\` на момент проверки **не имела защиты Rulesets**. Добавление правила для \`main\` через GitHub Settings требует административного доступа. Не включайте общий запрет обычных обновлений: VK и GigaChat пишут в \`main\` из GitHub Actions.
- **Публичную HTML/CSS/JavaScript-страницу нельзя сделать некопируемой.** Любой посетитель технически может сохранить загруженные браузером файлы. Публичный репозиторий GitHub также позволяет скачивать исходники. Юридическое уведомление о правах сдерживает несанкционированное переиспользование, но не техническое копирование.
- Делать репозиторий приватным **без проверки тарифного плана GitHub Pages нельзя**: на GitHub Free это может отключить публикацию. Даже если приватный репозиторий поддерживает Pages, браузерные файлы публичной страницы остаются доступными посетителю.

## Что не делает личное пространство

- Не предоставляет авторизацию или облачные аккаунты пользователей.
- Не позволяет менять настоящую публичную базу депутатов.
- Не синхронизирует личные правки между устройствами автоматически.
- Не отправляет локальные правки в GigaChat; после локального редактирования текста категория может определяться локальными правилами.
- Не показывает секретные ключи \`GIGACHAT_AUTH_KEY\`, \`VK_TOKEN\` или \`APIFY_TOKEN\` и не позволяет менять их из интерфейса.

При использовании чужих фотографий и публикаций сохраняйте ссылки на первоисточники и уважайте права их авторов.
