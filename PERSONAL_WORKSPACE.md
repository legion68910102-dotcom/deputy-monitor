# Локальные исправления (интерфейс «Личное пространство» удалён)

**23 ноября 2026 года** отдельная вкладка «🔒 Личное пространство» удалена по решению владельца проекта. В опубликованной версии ЮАО она **больше не отображается**. Архивная инструкция по использованию этой вкладки была заменена этим описанием.

## Что сохранено

- Приложение продолжает показывать общую опубликованную базу депутатов, публикации VK и результаты GigaChat.
- В разделе **«🧠 Анализ деятельности по текстам»** остаётся кнопка **«🔁 Это репост (только у меня)»** для публикаций, где исторический импорт потерял информацию об источнике. Такая исправленная метка сохраняется лишь в браузере и не изменяет общую базу.
- Существующие пользовательские операции с импортом CSV, карточками, фото и архивом по-прежнему используют локальное хранилище браузера. Их данные не переносятся автоматически между устройствами.
- Существующие локальные данные браузера **не очищаются** при удалении вкладки; код сохранения совместимости оставлен для того, чтобы не нарушить работу анализа.
- Автоматический сбор VK, классификация GigaChat, отчёты и рейтинги не зависят от удалённого интерфейса.

## Планируемая модель коммерческой платформы

Для будущей единой платформы Москвы предусмотрены отдельные данные каждого округа, вход по учётной записи и серверные ограничения ролей:

- **Администратор района:** только просмотр данных своего района.
- **Администратор округа:** просмотр и редактирование данных всех районов своего округа.
- **Владелец платформы:** управление всей системой и заказчиками.

**Эти серверные роли ещё не реализованы.** В текущем статическом приложении операции редактирования не становятся общими изменениями без авторизованного серверного механизма.
