Отчёт Excel

По депутату или всем сразу

Выберите депутата и календарный период. Скачайте таблицу CSV, которая открывается в Excel. Скачивание XLSX временно отключено из-за ошибок открытия на iPhone. Если видите старую страницу, откройте её с параметром обновления в адресе. Даты включаются в отчёт полностью.

Отчёт строится из публикаций, загруженных в этот браузер через CSV. Пока автоматический сбор VK не подтверждён, это не полный отчёт о деятельности депутатов. Если данных нет, файл всё равно содержит сводку и заголовки таблицы.

Автоматические проверки

Сбор настроен на ежедневный запуск. Для чтения публичных стен VK API требуется действующий пользовательский или сервисный ключ. Пока ключ не настроен, публикации автоматически не поступают. Регистрация ИП или самозанятости для работы сайта не нужна.

Добавить публикацию VK

Если вы видите пост во ВКонтакте, его можно внести прямо с телефона. Сохраняются только сведения, которые вы укажете; данные VK автоматически не считываются.

Импорт CSV

Файл UTF-8 с колонками profile,date,url,text,likes,comments,reposts,views,followers. Дата в формате ГГГГ-ММ-ДД. Отсутствующие метрики оставляйте пустыми.

Методика оценки

Оценка не рассчитывается, пока нет подтверждённой полноты данных. Показатели социальных сетей характеризуют публичную коммуникацию, а не всю депутатскую деятельность.
