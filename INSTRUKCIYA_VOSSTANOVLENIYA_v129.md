## 2. Как восстановить сайт в новом репозитории GitHub

1. Скачайте ZIP исходного кода по ссылке выше. Распакуйте его, сохранив структуру папок и скрытый каталог `.github/workflows/`.
2. Создайте новый пустой репозиторий GitHub, скопируйте содержимое архива в корень ветки `main` и зафиксируйте изменения.
3. В **Settings → Pages** разрешите GitHub Pages и публикацию через GitHub Actions. В архиве есть workflow `.github/workflows/pages.yml` с названием **Publish deputy monitor**.
4. В **Settings → Actions** разрешите запуск workflows, если он ограничен.
5. Восстановите нужные секреты GitHub Actions (см. ниже) — **не** добавляйте их в исходный код.
6. После отправки файлов на `main` публикация обычно запускается автоматически; при необходимости выполните **Actions → Publish deputy monitor → Run workflow**.
7. Откройте `index-v129.html` на новом домене GitHub Pages и проверьте карточки, фильтры и анализ.

## 3. Какие секреты и переменные нужны

Путь: **Settings → Secrets and variables → Actions**.

- `GIGACHAT_AUTH_KEY` — закрытый ключ GigaChat для ИИ-классификации.
- `VK_TOKEN` — токен официального VK API с доступом к методу `wall.get`. Его наличие и работоспособность для всех профилей пока **не подтверждены**.
- `GIGACHAT_CA_PEM` — необязательный сертификат при необходимости; workflow поддерживает проверку корневого сертификата.
- `APIFY_TOKEN` — только при использовании старого ручного импорта Apify.
- **Repository variable** `VK_COLLECTION_ENABLED=true` — включать **только после** успешной проверки VK API.

Секреты GitHub Actions нельзя восстановить из ZIP. Если значения не сохранены в безопасном менеджере паролей, их нужно получить или перевыпустить у соответствующего провайдера. **Не отправляйте пароли, токены и одноразовые коды по обычной почте или в чат.**

## 4. Проверка автоматизации

1. **Actions → AI classification of deputy publications**: запустите workflow на `main`, проверьте логи и файл `ai-analysis.json`.
2. **Actions → Collect public VK posts (official API; 159 profiles)**: сначала `mode=test` — только локальные тесты без запросов VK.
3. После настройки `VK_TOKEN`: `mode=pilot` — пробные запросы для первых пяти профилей, без изменения файлов.
4. Только если пилот прошёл: `mode=full`, `confirm_full=YES`, ветка `main`.
5. После успешного полного сбора можно включить переменную `VK_COLLECTION_ENABLED=true` для ежедневных запусков.
